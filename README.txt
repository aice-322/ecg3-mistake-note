# 心電図検定3級｜間違いノート

iPhoneのSafariで使える、HTML/CSS/JavaScript製の学習Webアプリです。

## 主な機能
- Part1〜Part4を分類して間違いを記録
- 問題番号、参考書ページ、自分の答え、正解、間違えた理由、正しい知識を保存
- P波 / QRS / T波 / PR / QRS幅 / QT / RR / ST-T / リズムなどをタグ付け
- 1日後→3日後→7日後→14日後→30日後の復習ルート
- Part別・テーマ別の進捗表示
- 検索、編集、削除
- JSONバックアップ／復元
- iPhone向けレスポンシブUI

## iPhoneで使う方法
1. このフォルダ一式をHTTPSで公開します。GitHub Pagesなどの静的ホスティングでOKです。
2. iPhoneのSafariで公開URLを開きます。
3. 共有 → 「ホーム画面に追加」→「Webアプリとして開く」をオン → 追加。
4. ホーム画面の「心電図3級」から起動します。

※学習データはブラウザのlocalStorageに保存されます。機種変更・サイトデータ削除に備えて「分析→バックアップ」でJSONを保存してください。
